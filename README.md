## ▶️ How to Run the Programs

1. Install Python 3
2. Download or clone the repository

```
git clone https://github.com/yourusername/AI-Lab.git
```

3. Navigate to the folder and run any program

```
python filename.py
```

Example:

```
python bfs.py
```
